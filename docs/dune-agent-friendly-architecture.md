# Dune：智能体友好型架构（Agent-friendly architecture）核心总结

Dune 是一种专为 **AI 编码智能体（agent）与多人协作**设计的架构哲学。它假设开发者或智能体通常只看到局部上下文，因此系统必须通过结构化约束来确保全局一致性、可维护性与安全性。

---

## 核心三原则解读

### 1. 常规路径比捷径需要更少的决策
架构必须让“正确的做法”更简单、更显而易见，让开发者或 AI 自然地走向安全路径。  
- **正常路径**：清晰、自动化、低决策成本  
- **捷径**：复杂、容易破坏边界、应当被阻止  
- **目标**：让系统自动引导 agent 做对的事，而不是依赖 agent 理解复杂架构。

---

### 2. 禁止的依赖关系会自动触发失败机制
任何跨越边界、破坏模块隔离的行为都必须立即失败。  
- **自动化拦截**：违反依赖 → 编译失败 / lint 失败 / CI 拒绝  
- **机制保障**：系统自动 enforce 架构，而不是靠人记规则  
- **目标**：防止 AI agent 在局部上下文中做出“看起来能工作但破坏架构”的修改。

---

### 3. 异常情况应当狭窄、明确，并作为架构变更进行审查
例外不能随意出现，也不能隐式存在。  
- **狭窄**：影响范围小，不扩散  
- **明确**：显式标注，不让 agent 误以为是常规模式  
- **审查**：任何例外都是架构事件，而不是普通代码修改  
- **目标**：避免例外变成隐性耦合点，污染系统主路径。

---

## 整体思想（一句话版）

> **让正确的路径更简单，让错误的路径直接失败，让例外必须被严格审查。**

这样 AI agent 即使只看到局部上下文，也能安全地做出“局部显而易见且全局正确”的修改。
